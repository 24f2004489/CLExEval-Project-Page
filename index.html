Project RARECASE-2000 Code

CLExEval studies clinical reasoning in language models through expert-curated rare cases, progressive information masking, model output evaluation, and human expert assessment across a seven-dimensional rubric.

500rare narratives selected
2,000RARECASE release instances
400model outputs evaluated
5,600expert-scored datapoints

Pipeline

Data curationExpert selection of 500 rare narratives from MultiCaRe.
Progressive maskingFive versions per case: narrative plus levels 0-3.
Model evaluationHuatuoGPT-o1-8B and GPT-4o-mini are evaluated across 200 instances each.
Expert assessmentTwo medical-resident raters score outputs using the CLExEval rubric.
